A deterministic Node.js program (standard library only) that draws a single 1024x1024 image summing up 24 November 2026's world news: five headline tiles — an Israeli strike in Gaza City, a Russian strike on Zaporizhzhia flats, a Houthi strike on Riyadh's PIF Tower, a gas blast at a Hanoi eatery, and landmine casualties hitting a five-year high — each with a headline, a sub-headline and a small illustration. Running it twice produces byte-identical output.

## Run it

```sh
node main.ts
```
